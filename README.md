# Carta Digital 💌

Prototipo visual premium y responsive de Carta Digital.

## Incluye
- Portada con reflexión del día.
- Fondo animado con luces y partículas.
- Sobre y carta animados.
- Corazones, estrellas, flores, mariposas y destellos.
- Botones con microanimaciones.
- Registro e inicio de sesión en modo DEMO usando localStorage.
- Modal de Panel Administrativo.
- Misión, Visión, Reviews y membresía de $20/mes.
- Adaptación para celular.

## Importante: registro, email y pagos reales
Esta versión es un **prototipo frontend**. El registro real, autenticación segura, envío automático de emails, revisión de cartas y cobro recurrente necesitan un backend y servicios externos.

Flujo recomendado para producción:
1. Base de datos + autenticación.
2. Servicio de email transaccional para el email de bienvenida.
3. Sistema de pagos recurrentes para la membresía de $20/mes.
4. Roles: miembro y administrador.
5. Moderación de cartas antes del envío.
6. Protección de contraseñas y datos.

Abre `index.html` en el navegador para probar el diseño.

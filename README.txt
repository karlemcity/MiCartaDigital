MI CARTA DIGITAL — LISTA PARA GITHUB

1. Descomprime este ZIP.
2. En GitHub abre el repositorio karlemcity/MiCartaDigital.
3. Add file -> Upload files.
4. Selecciona index.html, styles.css, app.js y .nojekyll.
5. Commit changes.

Esta es una versión frontend: navegación, diseño, formularios y ventanas funcionan en el navegador.

Para convertirla en una plataforma comercial real todavía hay que conectar:
- cuentas/autenticación
- base de datos
- pagos recurrentes de $20
- panel privado de administradora
- revisión/aprobación de cartas
- asignación de grupos de 10
- envío seguro de cartas
